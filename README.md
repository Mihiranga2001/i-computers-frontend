# i-Computers - E-Commerce Frontend Application

## 📌 Project Overview

i-Computers is a modern e-commerce frontend application developed as
part of my software development course.

The main objective of this project was to design and develop a
user-friendly online computer store interface where users can browse
products, view product details, manage their shopping cart, and interact
with an e-commerce platform.

This project helped me gain practical experience in modern frontend
development using React and related technologies.

------------------------------------------------------------------------

# 🚀 Features

## User Features

-   Responsive e-commerce user interface
-   Browse computer products
-   View product details
-   Product category navigation
-   Search products
-   Add products to cart
-   Update cart quantities
-   Remove products from cart
-   User authentication interface
-   User profile interface
-   Order management interface
-   Product review interface

# 📚 Libraries & Packages

## React Router

Used for managing navigation between different pages.

Examples: - Home page - Product page - Cart page - Login page - User
profile page

## Axios

Used for handling communication between frontend components and backend
APIs.

## React Hot Toast

Used to display user-friendly notifications.

Examples: - Product added successfully - Login messages - Error
notifications

# ⚙️ Installation & Setup

## Prerequisites

-   Node.js
-   npm

## Clone Repository

``` bash
git clone <repository-url>
```

## Navigate to Project Folder

``` bash
cd i-computers-frontend
```

## Install Dependencies

``` bash
npm install
```

## Run Development Server

``` bash
npm run dev
```

Application runs on:

    http://localhost:5173

------------------------------------------------------------------------

# 🧪 Testing

Run frontend tests:

``` bash
npm test
```

Generate test coverage:

``` bash
npm run test:coverage
```
